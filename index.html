GT API Docs

GameTrustAPI

As of 8/7/2026, GameTrustAPI is actively being developed. This documentation has been created early to explain how the API will work once the backend and SDK are complete.

This documentation explains the planned usage and features of GameTrustAPI.

How To Use

After installing the SDK Unity package and adding the required references, setup is simple.

Initialize your project using your provided project slug: 

GTAPI.Init("your-slug");

Including the slug in your production build is safe.

Requesting Data

Data requests can be made using: 

GTAPI.DataX

X is a placeholder. Available fields are:

  • Data1
  • Data2
  • Data3
  • Data4
  • Data5

Data is returned after GT API verifies the build and confirms the request is not abusive.
