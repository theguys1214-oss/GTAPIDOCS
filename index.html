Welcome to the docs for GTAPI1

as of 8/7/2026 it is actively being developed, I figured I would make a doc anyway, this doc shows how to use it for when the backend and SDK is done.

How To Use

after installing the SDK (unity package), its quite simple. after references, you init your project's slug provided on purchase, to do this you would use GTAPI.init("your-slug") including the slug in production is fine. after init, to make a data request you simply use GTAPI.datax x is just a placeholder, you can do data1-5, configurable through request. It returns any info you set it to after it checks your build and that the request isn't just a spam request.
