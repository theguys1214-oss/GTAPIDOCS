GameTrustAPI

As of 8/7/2026, GameTrustAPI is actively being developed. This documentation has been created early to explain how the API will work once the backend and SDK are complete. join the discord!

This documentation explains the planned usage and features of GameTrustAPI.

How To Use

After installing the SDK Unity package and adding the required references, setup is simple.

Initialize your project using your provided project slug: 

GTAPI.Init("your-slug");

Including the slug in your production build is safe.

Requesting Data

After initialization, data can be requested using: 

GTAPI.DataX

The X is a placeholder. Available fields are:

  • Data1
  • Data2
  • Data3
  • Data4
  • Data5

Data is returned after GT API verifies the build and confirms the request is not abusive.

Values returned

Besides returning normal data, the API will return multiple codes for different things you can build on.

  • 1

    • Common, one of the checks failed.

  • 2

    • The public endpoint couldn't reach any of the DBs. DM the developer, as this could be serious.

  • 3

    • Uncommon, the device is temporarily banned for failing critical checks repeatedly.

  • 4

    • Uncommon, the device has been permanently banned by the automated system for repeatedly failing critical checks (more info below).

you can build around these codes inside the sdk, more info provided soon.

HOW TO APPEAL A PLAYER DEVICE BAN.

Device bans are serious although rare, they prevent one device from playing any game using the GT API.

Device bans are issued from the automated system through a strike system. To appeal a player ban as either a player or developer, contact the GT API team.

  • 5 strikes

    • 5 day temp ban from services.

  • 10 strikes

    • 1 week temp ban from services.

  • 20 strikes

    • 2 week temp ban from services.

Past 20 strikes will be permanant but you may appeal. Strikes are a add system, 5 stikes is one temp ban, those strikes remain for the month.
