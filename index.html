GameTrustAPI

As of 8/7/2026, GameTrustAPI is actively being developed. This documentation has been created early to explain how the API will work once the backend and SDK are complete.

This documentation explains the planned usage and features of GameTrustAPI.

How To Use

After installing the SDK Unity package and adding the required references, setup is simple.

Initialize your project using the project slug provided after purchase: 

GTAPI.Init("your-slug");

Including the slug in your production build is safe. The slug identifies your project and does not provide direct access to protected data.

Requesting Data

After initialization, data can be requested using: 

GTAPI.DataX

The X is a placeholder. Available data fields are:

  • Data1
  • Data2
  • Data3
  • Data4
  • Data5

These fields are configurable per project. Data is only returned after GT API verifies the build and confirms the request is not abusive.
